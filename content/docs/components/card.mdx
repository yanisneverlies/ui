## Anatomy

```tsx title="Anatomy"
<Card>
  <CardPanel>
    <CardHeader>
      <CardTitle />
      <CardDescription />
      <CardAction />
    </CardHeader>
    <CardContent />
  </CardPanel>
  <CardFooter />
</Card>
```

In the default `shell` variant, `CardPanel` is the raised surface inside a tinted frame, and `CardFooter` sits on the frame below it.

## Concentric corners

The panel takes the theme's `--radius`. The frame adds its inset on top, so the curves stay concentric. A button that ends the footer gets the panel's radius too, so its corner follows the frame.

| Variable | Default | Set on |
| --- | --- | --- |
| `--card-inset` | `8px` | `Card` |
| `--card-radius` | `--radius` + `--card-inset` | `Card`. Override it only to break the link on purpose. |

## Surface

For a single raised card with no frame, use `variant="surface"` and put the parts straight inside it.
