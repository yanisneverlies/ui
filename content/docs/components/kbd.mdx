## Keys pressed together

Wrap them in `KbdGroup`:

```tsx title="Usage"
<KbdGroup>
  <Kbd>⌘</Kbd>
  <Kbd>K</Kbd>
</KbdGroup>
```

## Inside a button

Use `variant="on-primary"` inside a primary button, and the default variant inside the others. See the first example on [Button](/docs/components/button).
