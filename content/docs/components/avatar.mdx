## Usage

```tsx title="Usage"
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar"

export function Reader() {
  return (
    <Avatar role="img" aria-label="Lucilius">
      <AvatarImage src="/lucilius.png" alt="" />
      <AvatarFallback>L</AvatarFallback>
    </Avatar>
  )
}
```

The fallback shows until the image loads, and stays if it fails. Name the person on the root with `aria-label`, as above, or put visually hidden text in the fallback. When a visible name sits beside the avatar, use an empty `alt` and `aria-hidden` on the fallback.

At `sm` (24 px) a text fallback shrinks to its first letter. Pass elements instead of a string to keep what you wrote.

## Image

The image covers the avatar. This one is a small SVG data URI, so it needs no file and no network request.

## Group

<ComponentPreview name="avatar-group" />

`AvatarGroup` overlaps its avatars by 8 px. Each gets a 2 px ring in the page color so the overlap reads. That ring is one of the few edges we keep (see the decisions list), and it is there to separate, not to decorate. Give the group an `aria-label`.
