## Tones

`destructive` is reserved for errors and failures, so nothing else should share its hue. `brand` marks the current item.

## Shapes

<ComponentPreview name="badge-shapes" />

Use `rect` for labels like branch names, and `pill` for statuses and counts. Add `tnum` to counts so they don't shift as they change.
