## Labels

Wrap the switch and its text in a `<label>`, so a click on the text flips it too. Give a switch with no visible text an `aria-label`.

## Sound

A switch plays `toggle` when sound is on, going up when it turns on and down when it turns off. Pass `sound={false}` on the switch that controls sound itself, so it doesn't cue its own state change.
